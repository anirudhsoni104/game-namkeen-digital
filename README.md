# Game Namkeen Digital Hub

Build a Premium Game Namkeen E-Commerce Website

Build a complete, production-quality, premium FMCG e-commerce website for Game Namkeen, using the uploaded product catalogue and all uploaded business documents as the primary source of truth.

Do NOT create a generic snack-company template. The website must look like a real Indian FMCG brand that could confidently sell products online, approach distributors, and present itself to retailers and business partners.

1. SOURCE OF TRUTH — VERY IMPORTANT

Carefully inspect every uploaded catalogue page, product image, business document, logo, company detail, product detail, address, phone number, social-media information, packaging image and other supplied material before building the website.

Use the uploaded materials as the authoritative source.

Do NOT:

Invent products

Invent product prices

Invent nutritional information

Invent ingredients

Invent certifications

Invent manufacturing claims

Invent awards

Invent company history

Invent addresses

Invent GST/FSSAI/license numbers

Invent product specifications

Invent testimonials or customer reviews

Invent distributor claims

Invent delivery promises

If information is not present in the uploaded documents, either omit it or create a clearly marked placeholder that can be edited later.

Preserve the exact product names and company information from the supplied documents.

2. BRAND POSITIONING

Brand:

GAME NAMKEEN

Core brand feeling:

Trust. Taste. Tradition.

Position the company as a modern Indian snack/FMCG brand combining:

Traditional Indian taste

The website should feel:

Premium + Indian + Modern + Trustworthy + Energetic + Appetizing

Avoid making it look childish, overly cartoonish, cheap, or like a generic ₹5 snack website.

3. VISUAL DESIGN DIRECTION

Create a highly polished visual identity inspired by premium FMCG brands and modern Indian food-commerce websites.

Use the actual Game Namkeen packaging photography from the uploaded catalogue wherever possible.

Premium product photography

Subtle shadows

Do not simply copy the catalogue's page layout.

Instead, transform the catalogue into a modern digital shopping experience.
